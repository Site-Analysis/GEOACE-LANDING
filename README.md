# GeoAce landing page

Landing page for GeoAce Studio, built with Next.js (App Router).

Live site: https://geoacestudio.com

## Run locally
```
npm install
npm run dev
```
Open http://localhost:3000. Pages: `/` (landing) and `/customers`.

## Deploy
Pushes to `main` run CI (`npm run build`) and deploy on Vercel to https://geoacestudio.com. `www.geoacestudio.com` redirects to the root domain.
